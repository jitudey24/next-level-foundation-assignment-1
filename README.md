# Next Level Foundation — Assignment 1

A set of JavaScript problem-solving exercises focused on core programming fundamentals. The repository contains five individual problem files and a combined answer file.

## Problems Covered
1. **Value Description** — identify a value's JavaScript type and whether it is truthy or falsy.
2. **Day Type Checker** — classify a day as a weekend, working day, or invalid day.
3. **Username Validation** — check username length, spaces, and reserved words.
4. **CNG Fare Calculator** — calculate a fare using distance, waiting time, and a night-time surcharge.
5. **Cricket Chase Verdict** — evaluate a run chase using the target, current score, and balls remaining.

## Files
- `problem-1.js` through `problem-5.js` — separate solutions for each exercise
- `answer.js` — combined solutions

## Technologies
- JavaScript (ES6+)

## Run Locally
1. Clone this repository.
2. Make sure Node.js is installed.
3. Run an individual solution:

```bash
node problem-1.js
```

Replace the filename to run another problem. You can also run the combined file:

```bash
node answer.js
```

## Learning Goals
- JavaScript data types and truthy/falsy values
- Conditional statements and switch cases
- String methods and validation
- Functions, parameters, and default values
- Arithmetic calculations and problem-solving logic
